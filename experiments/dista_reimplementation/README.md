# DISTA-Net Reimplementation Results

This directory stores the experimental results obtained using our reimplementation of **DISTA-Net**, which serves as the dynamic deep unfolding backbone inherited and further extended in **DISTA-Net++**.

## Background

As part of DISTA-Net++, we provide a new implementation of the original DISTA-Net.

The reimplementation adheres to the core ideas and methodological principles of the original paper while adopting a more efficient implementation and optimized code structure.

This directory specifically contains the experimental outputs generated by this new implementation, rather than the implementation source code itself.
