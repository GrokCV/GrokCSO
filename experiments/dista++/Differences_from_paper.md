# DISTA-Net++ Experimental Results

This directory contains training and evaluation logs and a model checkpoint for **DISTA-Net++**, provided for reference and further evaluation.

## Notes on the Released Results

The results in the provided logs are generally consistent with those reported in the paper. Some metrics, such as **PSNR**, show minor numerical differences, while most metrics remain comparable to or better than the reported values, including **CSO-mAP**, the primary evaluation metric. These differences do not affect the main conclusions of the paper.

The original logs associated with the paper's reported results are no longer available, so this directory contains the experimental records currently available to us.

We apologize for any inconvenience this may cause when comparing the logs with the paper and appreciate your understanding.
